# Marketing Skills

Open-source skills that turn coding agents into practical marketing operators.

## Skills

- [SEO Operator](https://github.com/marketingskills/seo): diagnose traffic decay, find keyword opportunities, check SERP authority, write refresh briefs, build proposals, and run closed-loop SEO growth workflows.

## Install

```bash
curl -fsSL marketingskills.net/seo | bash
```

Or install individual skills:

```bash
npx skills add marketingskills/seo/skills/traffic-decay-detector
npx skills add marketingskills/seo/skills/live-search-console-data
npx skills add marketingskills/seo/skills/authority-mark-keyword-difficulty
npx skills add marketingskills/seo/skills/seo-growth-loop
```

## Purpose

Marketing Skills packages repeatable marketing judgment, workflows, and tool instructions into portable agent skills. The goal is simple: make agents useful on real marketing work, not just generic writing tasks.
