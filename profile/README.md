Give Claude Code, Codex, Gemini, OpenCode, Hermes and other coding agents repeatable methods for SEO, growth, content, GTM and creative work.

## Start here

Install SEO Operator:

```bash
curl -fsSL https://marketingskills.net/seo | bash
```

Or install an individual operator with the Agent Skills CLI:

```bash
npx skills add marketingskills/computed-knowledge-seo
npx skills add marketingskills/plain-language-editor
npx skills add marketingskills/open-source-growth
```

Not sure which one you need? Give your agent this:

> Browse https://marketingskills.net/skills/ and choose the appropriate Marketing Skills operator for this task.

## What is an operator?

A Marketing Skills operator packages more than a prompt. It can contain:

- a repeatable decision process
- domain-specific judgement
- agent instructions
- scripts and deterministic utilities
- examples and references
- tool integrations
- ways to verify the result
- loops for continuing the work

The goal is to make agents useful on real marketing work, not just generic writing tasks.
